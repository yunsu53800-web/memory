## 썸네일 자동화 시스템 입력 변수 최종 점검

'흑룡' 브랜드 시스템(#A, #B)과 타깃 감정('찬근감')을 반영하여, 영상 제목/후크 입력 시 디자인 생성을 위한 필수 입력 변수(Variable)를 최종적으로 정의합니다. 이 변수들은 디자인 자동화 시스템의 핵심 제약 조건으로 작용합니다.

### 1. 브랜드 시스템 변수 (Brand System Variables)

이 변수들은 디자인의 근간을 이루며, 절대로 변경되어서는 안 되는 고정값입니다.

| 변수명 | 값 | 설명 |
| :--- | :--- | :--- |
| **Brand_Color_A** | `#1A1A1A` (짙은 검정/흑색) | 흑룡의 주조색. 권위와 깊이를 상징. |
| **Brand_Color_B** | `#C18F44` (황갈색/골드 계열) | 찬근감과 시니어의 깊은 경험을 상징하는 강조색. |
| **Target_Emotion** | 찬근감 (Vigor/Strength) | 디자인이 반드시 전달해야 할 핵심 감정. (핵심 제약 조건) |
| **Tone_Rule** | 작설적 테이트 기반, 찬근감 | 모든 시각적 요소에 적용되는 톤앤매너 규칙. |

### 2. 콘텐츠 입력 변수 (Content Input Variables)

사용자가 입력하는 텍스트를 디자인 요소로 변환하기 위한 변수입니다.

| 변수명 | 입력 형태 | 설명 | 필수 여부 |
| :--- | :--- | :--- | :--- |
| **Video_Title** | 텍스트 | 영상의 핵심 제목. (클릭베이트 금지 원칙 적용) | 필수 |
| **Video_Hook** | 텍스트 | 시청자의 호기심을 자극하는 후크 문구. | 필수 |
| **Target_Audience_Context** | 텍스트 | 타깃 청중(50대 이상 시니어 건강)에 대한 간략한 맥락. | 필수 |

### 3. 레이아웃 및 스타일 변수 (Layout & Style Variables)

자동화 시스템이 최종적으로 적용할 레이아웃 및 스타일 규칙입니다.

| 변수명 | 값/규칙 | 설명 |
| :--- | :--- | :--- |
| **Layout_Style** | 중앙 정렬 + 대비 강조 | 제목과 후크가 중앙에 배치되며, `Brand_Color_B`를 사용하여 핵심 메시지를 강조하는 레이아웃. |
| **Text_Hierarchy** | Title (가장 큼) > Hook (중간) > Context (가장 작음) | 정보의 중요도에 따라 폰트 크기와 굵기를 차등 적용. |
| **Color_Application** | `Brand_Color_A` 배경, `Brand_Color_B` 강조선 | 전체적인 배경은 흑색 계열로 무게감을 주고, 강조색으로 '찬근감'을 부여. |
